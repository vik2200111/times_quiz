# Quiz Times

Веб-приложение для проведения научно-популярного квиза с экраном ведущего и экранами участников.

## Запуск на MacBook (локальная сеть / точка доступа)

```bash
npm install
npm start
```

Сервер слушает все интерфейсы (`0.0.0.0:3000`), поэтому к нему можно подключиться с телефонов в той же Wi‑Fi сети.

### Как раздать квиз с ноутбука

1. На Mac включите **Режим модема** (точка доступа) или подключите всех к одной Wi‑Fi сети.
2. Запустите `npm start`.
3. Откройте **экран ведущего** на Mac: `http://localhost:3000/host.html`
4. На экране ведущего появится ссылка вида `http://192.168.x.x:3000/player.html` — скопируйте её игрокам.
5. Участники открывают эту ссылку в браузере телефона (до 30 человек).

Если iPhone не открывает страницу, убедитесь, что Mac и телефоны в одной сети и файрвол не блокирует порт 3000.

## Бесплатный хостинг

Можно выложить тот же проект на Render, Railway или аналог:

- Start command: `npm start`
- Переменная `PORT` задаётся хостингом автоматически
- Опционально `PUBLIC_URL=https://ваш-домен` — тогда ведущий увидит публичную ссылку для игроков

## Страницы

- **Главная:** `/`
- **Ведущий:** `/host.html` — вопросы, таймер, правка баллов (+/−)
- **Игрок:** `/player.html` — регистрация и ответы

## Как играть

1. Участники открывают `/player.html` и регистрируются (до 30 человек/команд)
2. Ведущий открывает `/host.html` и нажимает «Начать квиз»
3. Вопросы идут автоматически:
   - Туры 1–3: 50 секунд на вопрос, затем 20 секунд повтор с ответом
   - Тур 4 (блиц): 15 секунд, без повторов
4. Ведущий может вручную добавить или снять балл у любого участника
5. В конце — турнирная таблица

## Баллы

- **Туры 1–3:** правильный = +1, неправильный = 0
- **Тур 4:** правильный = +1, пустой = 0, неправильный = −1

## Призы

- Места 1–3: «Подойдите к ведущему за призом»
- Места 4–30: «Спасибо огромное за участие! Надеемся, вам было с нами интересно!»
